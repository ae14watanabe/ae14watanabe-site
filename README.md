# ae14watanabe-site

Personal intro site for [@ae14watanabe](https://x.com/ae14watanabe).

🌐 **Live**: <https://ae14watanabe.vercel.app>

## Stack

- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)

## Development

```bash
npm run dev
```

Open <http://localhost:3000>. The page lives in `app/page.tsx`.

## Deploy

Pushes to `main` deploy automatically via the Vercel GitHub integration.
For manual deploys: `vercel --prod`.
